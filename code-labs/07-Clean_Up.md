## 7\. Clean Up

To avoid any unforeseen billing charges or clean up your workspace resources:

1. In Google AI Studio, go to the [Apps page](https://aistudio.google.com/app/apps?authuser=1).
2. Find your application in the grid or list.
3. Click the trash icon to delete the app state and unpublish the service from Cloud Run.
4. If you deployed using a standard project and want to shut down all resources entirely, go to the [Google Cloud Console Project Settings](https://console.cloud.google.com/?authuser=1) and delete the underlying project.

## 3\. Create a Portfolio Website in AI Studio Build Mode

Create the application shell and prompt the AI code assistant to build the frontend layout.

1. Navigate to [Google AI Studio Apps panel](https://aistudio.google.com/apps?authuser=1) and click **New App**.
2. In the chat prompt box, enter the description for your portfolio application:

```language-text
 Build a professional personal portfolio website. The site should
 have a modern, responsive design and sections for my biography,
 projects showcase, skills, and links to my professional profiles
 (e.g., GitHub, LinkedIn).
```

   [This link](https://aistudio.google.com/apps?prompt=Build+a+professional+personal+portfolio+website.+The+site+should+have+a+modern%2C+responsive+design+and+sections+for+my+biography%2C+projects+showcase%2C+skills%2C+and+links+to+my+professional+profiles+%28e.g.%2C+GitHub%2C+LinkedIn%29.&authuser=1) will automatically fill the prompt box for you.

3. Click **Build** to start the application generation process.

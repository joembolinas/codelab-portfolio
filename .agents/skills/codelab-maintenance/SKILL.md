# Codelab Maintenance

1. Read `AGENT.md` and the affected files.
2. Classify content as canonical instruction, transcript, optional guidance, warning, or reference.
3. Preserve chapter order and stable filenames.
4. Verify changed local links, anchors, images, footnotes, and fences.
5. Verify time-sensitive Google claims against official sources.
6. Review the diff for accidental scope and unsupported completion claims.
7. Report checks performed and label unavailable checks `Verification pending`.

This skill does not prohibit coding. For application work, first use the planning workflow and then apply the project's actual runtime conventions and validation commands.

For documentation-only commits, prefer `docs:`; for agent infrastructure, prefer `chore(agents):`.

# Reusable prompt: update one chapter

Update the requested codelab chapter only.

Context to inspect first:

- `AGENT.md`
- `.agents/instructions/INSTRUCTIONS.md`
- `README.md`
- the target chapter and its adjacent chapters

Requirements:

- Preserve the chapter's learning objective and numbered sequence.
- Use concise, learner-facing instructions.
- Keep transcript commentary separate from required steps.
- Preserve or repair valid Markdown links and admonitions.
- Cite official Google sources for current product facts.
- Avoid inventing UI labels, pricing, quotas, or deployment results.
- Review the final diff and list validation performed.

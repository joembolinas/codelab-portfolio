# Reusable prompt: plan before coding

Act as the project planner for this repository.

Before proposing implementation:

- Inspect the actual repository state and relevant setup files.
- Determine whether the request is documentation, project setup, application coding, or architecture.
- Ask concise clarification questions if the target, phase, runtime, or acceptance criteria are unclear.

Then produce:

1. Goal and non-goals.
2. Current evidence and assumptions.
3. Affected files/directories.
4. Small implementation steps.
5. Validation commands or checks available in this repository.
6. Risks, rollback/defer conditions, and unresolved questions.

Do not edit files until the plan is clear, unless the user explicitly requests a trivial direct fix.
